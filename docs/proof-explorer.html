02 / NO AWS ACCOUNT REQUIRED

From zero Docker to your application invariant.

1

Run the offline first check

Node.js 20+ and Git. No Docker, cloud credentials, or AWS account. This checks generated architecture files only; it does not run AWS APIs.

git clone --depth 1 --branch master https://github.com/B11-Health/aws-emulator-mcp.git
cd aws-emulator-mcp
node bin/aws-emulator-mcp.mjs try --json

Expect passed: true, artifactCount: 7, dockerUsed: false and cloudCallsMade: false.

2

Inspect source without executing it

Host Python 3.10+ is also required. The inspector finds literal client calls and input keys; its suggested case is intentionally not runnable until a developer reviews and completes it.

node bin/aws-emulator-mcp.mjs app-case-inspect examples/app-case/fixed.py examples/app-case/sqs-idempotency.json --json

Look for executedSource: false, executedAWSCalls: false and caseReview warnings.

3

Run the same assertion on both revisions

Requires a local Docker Engine in Linux-container mode and enough disk for the initial signed emulator image. Execute only Python you own and trust, never untrusted PR code. Use synthetic data.

node bin/aws-emulator-mcp.mjs app-case-compare examples/app-case/buggy.py examples/app-case/fixed.py examples/app-case/sqs-idempotency.json --json

Inspect bugReproduced, fixVerified, the failed regression path, the case/source hashes, both cleanup results and productionAwsValidated: false.

The application comparison exists on the current development master, not in the older beta.15 release tag. Exact behavior may change before the next release. See the proof recipe for a review checklist and limitations.

03 / WHERE THIS STOPS

Know what the green check cannot prove.

This verifies one trusted local Python entrypoint and its named synthetic invariant, not an arbitrary repository, real AWS IAM, production fidelity, process-crash recovery, or source-code security. To assess an app's AWS-operation compatibility, consult the official AWS Emulator fidelity guidance as well. If native AWS SDK tests meet your needs, you may not need our MCP adapter.
